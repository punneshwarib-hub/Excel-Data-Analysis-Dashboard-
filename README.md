# Automated Excel BI Dashboard for KPI & Performance Analysis
## Project Objective 
To design and develop an end-to-end interactive Business Intelligence dashboard in Microsoft Excel that automates data cleaning, modeling, and KPI reporting using Power Query, Power Pivot, and DAX, enabling stakeholders to analyze performance trends, monitor key metrics, and make data-driven decisions with minimal manual effort.

## 1. Business Problem Statement
Organizations often work with large volumes of raw data but lack a structured and automated way to convert this data into meaningful insights. Manual data cleaning, repeated calculations, and static reports lead to inefficiencies, errors, and delayed decision-making.

The business requires a solution that can:
- Clean and prepare raw data efficiently
- Calculate key performance indicators (KPIs) accurately
- Provide interactive and dynamic reporting
- Reduce manual reporting effort
- Enable stakeholders to explore insights independently
## 2. Project Objective
To design and develop an **end-to-end interactive Business Intelligence dashboard in Microsoft Excel** that automates data cleaning, modeling, and KPI reporting using Power Query, Power Pivot, and DAX, enabling faster and more reliable data-driven decision-making.
